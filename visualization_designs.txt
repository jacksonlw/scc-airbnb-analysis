Explanation of Visualization Designs

Published Website URL: https://jacksonlw.github.io/scc-airbnb-analysis/

1. Airbnb Performance Score Map in the Bay Area (Map)
This interactive score map uses a geospatial approach to plot Airbnb listings across the Bay Area and communicate their performance scores. Using geopandas, we visualized a sequential colormap ranging from light yellow to deep red—to intuitively indicate performance variation. Through a color-mapping process, lighter hues signal lower scores while darker reds highlight high-performing listings to make spatial patterns stand out. Users can hover over individual listings to view key metrics such as name, performance score, review rating, and number of reviews, enhancing interactivity and contextual understanding. The map also includes zoom and pan functionality, allowing for detailed exploration of neighborhoods. For instance, users can easily identify clusters of high-performing listings in areas like Palo Alto, and contrast them with lower-performing areas such as East San Jose. The map is embedded cleanly within the webpage using a simple title and minimal styling, ensuring that the data remains the focal point. A legend is also attached for ease of understanding. 

2. Relationship Between Room Type and Price (Box Plot)
The box plot plays a crucial role in setting the stage for this performance 
score calculation by visually highlighting how pricing varies across different 
room types. It reveals the extent of variation, median price points, and the 
presence of outliers, allowing us to see, for example, that Entire home/apartment 
listings span a much broader price range than Shared or Private rooms. However, 
we want to be able to see how similar housing types compare to other housing types 
in the same category, such that we can see the best performing airbnbs across all 
categories instead of the priciest one. Hence, we created a performance_score variable 
that will be used in the following visualizations. 

3. Validating Performance Score Using Price and Availability (Scatter Plot)

This scatter plot uses dots as marks to represent individual Airbnb listings. The x-axis shows the price per night (USD), and the y-axis shows the availability over the next year, meaning how many days the listing is available. Color is used as a channel to represent each listing’s performance score with lighter yellow indicating lower performance and dark red showing higher performance. We use red to keep the Airbnb theme consistent across the website. This sequential color scheme is explained in the legend at the top.

4. Average Review Ratings by Performance Tier (Bar Plot)

This bar chart uses horizontal bars to show the average review ratings across different performance tiers. The y-axis lists review categories like Accuracy and Location, while the x-axis shows the average rating on a scale from 4.5 to 5. Color is used as a channel to represent the performance tier—green for High, orange for Medium, and red for Low. These colors are intentionally chosen to show how well a listing performs, with green signaling better performance and red signaling worse performance. The interaction allows users to highlight specific review categories across all performance tiers, improving comparison capabilities.

5. Performance Score Distribution by Amenity Type (Box Plot)

This side-by-side box plot shows the distribution of performance scores for different Airbnb amenity types. Each box represents a different amenity type and shows the spread of performance scores. Color is used as a channel to show which amenity group each box belongs to, such as Outdoor & Safety or Comfort & Tech. There’s interactive selection boxes on the left where you can select one-to-many amenity groups. Groups that are not selected will fade on the box plot, making it easy for users to compare groups they are interested in.
